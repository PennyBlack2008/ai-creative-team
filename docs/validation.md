# 검증 기록 — 1.0.0

검증일: 2026-10-10. 아래의 자동 검사와 작성자 검토는 실제 서비스별 행동 평가와 다릅니다.

| 검증 | 결과 | 범위 |
|---|---|---|
| 배포 생성·일치 | 통과 | 원본 모듈 전체와 단일 프롬프트 일치 |
| 오프라인 자동 검사 | 13개 통과 | 빌드·버전·링크·예제 시간·사례 구조 |
| 작성자 규칙 검토 | 완료 | 승인 범위, 공통 수정 예산, 증거 범위, 상태 복원, 전문 모듈 간 충돌 검토 |
| ChatGPT 실제 채팅 평가 | 미실행 | 서비스·모델별 관찰 로그 없음 |
| Claude 실제 채팅 평가 | 미실행 | 서비스·모델별 관찰 로그 없음 |
| 실제 영상·이미지 생성 평가 | 미실행 | 생성물 없음 |

행동 평가용 18개 사례는 [평가 절차](../tests/README.md)와 [사례 원본](../tests/cases.json)에 있습니다. 예제는 작성된 참고 출력이며 실측 성공률을 나타내지 않습니다. 정적 검사 통과를 행동 평가 통과로 해석하지 마세요.

작성자 검토에서 확인한 설계 경계:

- 명확한 초안 위임은 재승인 없이 진행하며 외부 실행 권한으로 확대하지 않습니다.
- 비평과 검증의 제작 복귀는 하나의 자동 수정 카운터를 공유합니다.
- 단계·계획·채팅 변경으로 수정 한도를 초기화하지 않습니다.
- 생성 프롬프트를 요청한 경우와 실제 미디어 파일을 요청한 경우의 완료 판정을 구분합니다.
- 카드의 과거 승인을 새 대화의 외부 실행 권한으로 사용하지 않습니다.

한계: 자연어 규칙의 준수는 모델에 따라 달라집니다. 다음 검증 과제는 두 서비스의 실제 응답을 동일 시나리오로 기록하는 것입니다.
