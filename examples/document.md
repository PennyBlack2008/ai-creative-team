# 문서 — 200자 이내 안내문

설명용 예제입니다.

## 요청

```text
공방 휴무 안내문을 200자 이내로 써줘.
10월 15일 하루 쉬고 16일부터 정상 운영해. 예약 문의는 기존 채팅으로.
친근하지만 이모지는 빼줘.
```

명확한 단일 문구 작성이므로 간단 경로로 바로 전달합니다.

## 결과 예시

> 공방은 10월 15일 하루 쉬어갑니다. 10월 16일부터 정상 운영하니 방문에 참고해 주세요. 예약 문의는 기존 채팅으로 남겨주시면 확인 후 안내드리겠습니다. 감사합니다.

제공된 날짜·문의 경로·말투를 반영한 짧은 본문입니다. 사용자가 요구하지 않은 휴무 사유, 연도·요일, 전화번호를 만들지 않습니다. 실제 게시를 요청한 것이 아니므로 게시 완료라고 하지 않습니다.
