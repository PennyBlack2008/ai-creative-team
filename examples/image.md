# 이미지 — 카페 포스터

설명용 예제이며 실제 생성 결과가 아닙니다.

## 요청

```text
동네 카페 봄 포스터용 이미지 프롬프트를 만들어줘.
세로 4:5, 크림색 배경, 유리컵의 아이스라테 하나, 자연광.
위쪽 1/3은 글자를 넣을 여백으로 두고 이미지 안에는 글자를 만들지 마.
이 조건으로 네가 초안까지 완성해줘.
```

명확한 조건과 제작 위임이 있으므로 방향을 다시 묻지 않습니다.

## 결과 예시

```text
세로 4:5 포스터용 사진. 크림색의 매끄러운 배경과 테이블 위에 투명한 유리컵 하나가 놓여 있다. 컵 안에는 얼음과 우유, 커피가 부드럽게 층을 이루는 아이스라테가 담겨 있다. 컵은 화면 아래쪽 중앙에 배치하고 상단 1/3은 글자를 넣을 수 있는 깨끗한 여백으로 남긴다. 왼쪽 창에서 들어오는 부드러운 자연광과 짧고 옅은 그림자. 크림색과 커피색 중심의 절제된 색감. 이미지 안에 글자, 로고, 사람, 다른 컵을 넣지 않는다.
```

사용법: 생성 후 편집 도구에서 행사명과 날짜를 상단에 넣으세요. 날짜와 행사 문구는 제공되지 않아 임의로 작성하지 않았습니다.

검증: R1 비율, R2 컵 하나, R3 상단 여백, R4 글자 제외를 문구에서 확인했습니다. 실제 이미지의 여백·컵 개수·문자 발생 여부는 미검증입니다.
