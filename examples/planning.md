# 기획 — 작은 전시 준비

설명용 예제입니다.

## 요청

```text
4주 뒤 1인 일러스트 전시를 열어. 장소는 확정됐고 작품 12점은 완성됐어.
준비 인력은 나와 친구 1명, 추가 예산은 50만 원이야.
새 굿즈는 만들지 않을 거야. 네가 실무 준비 계획을 짜줘.
```

## 결과 예시

복합 작업으로 일정과 의존 조건을 묶습니다. 현재 제약 안에서 실행 계획 작성을 위임받았으므로 재승인은 필요하지 않습니다. 시작 날짜가 없으므로 달력 날짜 대신 전시일 기준 상대 주차로 제시합니다.

| 시점 | 할 일 | 담당 제안 | 선행 조건 | 완료 기준 |
|---|---|---|---|---|
| D-4주 | 벽면 치수·설치 규정 확인 | 본인 | 장소 담당자 정보 | 12점 배치도 초안 |
| D-3주 | 인쇄·액자·운송 견적 비교 | 본인 | 작품 치수 | 합계 50만 원 이내 선택안 |
| D-2주 | 작품 설명·온라인 초대 이미지 작성 | 친구 | 작품 제목·소개 | 12점 라벨과 초대 이미지 초안 |
| D-1주 | 설치 순서·물품 확인 | 두 사람 | 확정 견적·규정 | 누락 물품 없는 설치 목록 |
| D-1일 | 설치·동선 확인 | 두 사람 | 장소 입장 가능 | 작품 수·라벨·동선 확인 |

예산 배분안은 인쇄·액자 30만 원, 운송·설치 15만 원, 예비비 5만 원입니다. **견적이 아닌 계획 가정**이며 실제 견적이 초과하면 규격·설치 방식을 조정합니다. 친구의 업무 수락도 확인이 필요합니다.

검토: 새 굿즈 제작을 추가하지 않았고, 12점 전시·인력 2명·예산 상한을 기준으로 작성했습니다. 견적, 장소 규정, 친구의 가능 시간은 미확인입니다. 구매나 초대 발송은 실행하지 않았습니다.
